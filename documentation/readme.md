# Documentation

This directory contains the documentation of the CFL NeTEx Profile.  
It is organised into two main sections:

- **00_introduction/**  
  Contains the introductory material: overview, general principles, conventions, data organisation and publication rules.

- **01_specifications/**  
  Contains the detailed specifications of the CFL profile.  
  This section describes the modelling rules, entity definitions, structural conventions and all normative content.

Additional folders and content will be added progressively as the profile evolves.
